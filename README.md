# Laboratorio — Material de clase

Material de la materia **Laboratorio** · Informática Aplicada, 1er año · INSPT-UTN · Comisión 1.604 · Ciclo lectivo 2026.

Acá vas a encontrar los ejemplos que aparecen en las presentaciones, los ejercicios de cada clase y las presentaciones en PDF. El material se va sumando a medida que avanza la cursada.

## Qué hay en cada carpeta

```
Git y GitHub/       Presentación de la clase (PDF)
HTML/               Presentaciones (PDF) y ejercicios de HTML
  Ejercicios/
CSS/
  Ejemplos/         El código de cada slide, listo para abrir y probar
    1. CSS básico/
    2. CSS avanzado/
  Ejercicios/       Los ejercicios de práctica de cada clase
```

- **Ejemplos:** cada carpeta tiene el número y el título de la slide donde aparece, con su `index.html` y su `estilos.css`. Abrilo, probalo y cambiá valores para ver qué pasa.
- **Ejercicios:** cada carpeta trae los archivos para arrancar. La consigna está en la slide del ejercicio, y los pasos también van comentados en el `estilos.css`.

## Cómo usarlo

1. **Descargá el material.** Arriba, en el botón verde **Code**, elegí **Download ZIP** y descomprimilo. Si ya usás Git, también podés clonar el repo:

   ```
   git clone https://github.com/FrancoSpinelli/Laboratorio-TN-2026-Publico.git
   ```

2. **Abrí la carpeta en VS Code.** Usá **Archivo → Abrir carpeta…** y elegí la carpeta del ejemplo o del ejercicio.
3. **Miralo en el navegador con Live Server.** Con el `.html` abierto, hacé clic en **Go Live** (abajo a la derecha). Cada vez que guardes, la página se actualiza sola.

> Si no ves **Go Live**, instalá la extensión **Live Server** desde la pestaña de extensiones de VS Code.

## Para tener en cuenta

- Los ejercicios **no se entregan**: son para practicar. Cada uno tiene en la presentación una slide **Resultado esperado** para que compares tu resultado.
- Las **soluciones** se publican más adelante, después de que tuviste tiempo de resolverlos.
- Si clonaste el repo, para traer el material nuevo corré `git pull` dentro de la carpeta.
